# Passi più rapidi se usi iPhone

1. Scarica e salva il file ZIP completo. Se la piattaforma Claude consente di allegare ZIP, allegalo; altrimenti estrailo nell'app File e carica i `.md`, `.sql` e sorgenti nel nuovo repo GitHub.
2. Apri una sessione **Claude Code** o altra esperienza Claude con accesso reale al repository, terminale e test. Con il solo Claude chat, il risultato potrebbe essere soltanto codice da trasferire manualmente.
3. Incolla tutto il contenuto di `01-PROMPT-MASTER-CLAUDE.md` come messaggio iniziale. Usa `README-START-HERE.md` come guida.
4. Crea un **nuovo repository privato** dedicato. Non utilizzare un repository condiviso con NOVA Marketing AI o altri prodotti.
5. Per testare la generazione AI effettiva, servirà un account e chiave API Anthropic (i piani Claude chat e i crediti API possono essere distinti); non committare i segreti.
6. Per versione con dati reali di concorrenza, avrai bisogno di un provider dati lecito/fornito da te e potenzialmente a pagamento. Finché non c'è, i dati di opportunità saranno solo demo/import manuali.
7. Alla prima consegna richiedi: URL testato, build passata, risultato ZIP reale, file prodotti e test KDP, elenco API mancanti. Non accettare uno screenshot come dimostrazione del software.

**Da ricordare:** nessun tool può garantire ricavi; prima pubblica un libro realmente valido e verifica vendite e margini su un test prudente.
