# Metodo copertine (editabile)

Questo file è letto dall'agente direttore artistico a ogni analisi. Scrivi qui le tue regole, i tuoi appunti e ciò che hai imparato:
cosa converte nella tua nicchia, colori e stili che funzionano, errori da evitare, come testi la copertina in miniatura.
Se resta vuoto, l'agente usa solo le buone pratiche generali indicate in `src/lib/ai/prompts.ts`.
